## 术语系统架构

术语处理流程：
1. 预加载 → 建立内存索引
2. 文本分析 → 提取关键词
3. 术语匹配 → 筛选相关条目
4. 提示注入 → 仅发送必要术语

性能保障：
- 索引查询时间复杂度：O(n) → O(1)
- 内存占用：约每万条术语占用1MB 

## API系统架构

API调用流程：
1. 配置初始化
   - 加载环境变量
   - 选择API端点
   - 设置模型参数
   - 配置重试机制

2. 模型选择策略
   - 初始翻译：Pro/deepseek-ai/DeepSeek-V3
   - 翻译反思：Pro/deepseek-ai/DeepSeek-R1
   - 翻译改进：Pro/deepseek-ai/DeepSeek-V3

3. 调用处理
   - 请求构建
   - 错误处理
   - 响应解析
   - 结果验证

性能优化：
- 使用异步调用
- 实现请求限流
- 优化重试策略
- 缓存响应结果

## 日志系统架构

日志分级：
1. INFO级别
   - API调用开始
   - 模型加载状态
   - 成功响应信息
   - 处理完成通知

2. WARNING级别
   - 重试警告
   - 性能警告
   - 配置警告
   - 非致命错误

3. ERROR级别
   - API调用失败
   - 配置错误
   - 模型加载失败
   - 系统异常

日志内容：
- 时间戳
- 日志级别
- 模块标识
- 详细信息
- 错误追踪

输出格式：
```
[时间] [级别] [模块] - 消息
详细信息（如有）
错误追踪（如有）
``` 

## 网络通信层
### 连接管理
1. 基础配置
   - API端点：`https://dashscope.aliyuncs.com/compatible-mode/v1`
   - 超时设置：连接30s/读取180s
   - 重试策略：指数退避（最多3次）

2. 安全配置
   - TLS 1.2+ 强制启用
   - 证书链验证
   - SNI(Server Name Indication)支持

3. 代理支持
   - 自动检测系统代理
   - 手动设置：`export HTTPS_PROXY=http://127.0.0.1:7897`
