# 舰队团队简报

737MAX-FTD-46-19002

问题标题：网络文件服务器系统2（NFS-2）硬件相关问题

![](images/6a5f0a361f745e3854a0f08ea7716af61d5e9f0bada7338e144811c38c102576.jpg)

# 修订说明

修订了状态部分、最终行动和里程碑部分，增加了连接器焊接接头故障日期。

# 适用性

适用于下面状态部分提到的序列号（S/Ns）的737 MAX飞机。

# 描述

737MAX运营商遇到了网络文件服务器系统（NFS）的问题。目前，已知NFS存在两个硬件相关问题：固态硬盘（SSD）和网络扩展设备（NED）子系统处理器（NSP）连接器故障。

## SSD故障症状：

• 开机后超过10分钟，NFS前面的故障指示灯持续亮起。

## SSD故障背景：

• Delkin（SSD供应商）的故障分析未能确定根本原因。
• Delkin试图通过固件更新解决问题，但没有产生积极效果。
主要假设是SSD在写入过程中遇到电源中断时容易出现问题。

## 连接器焊接接头故障症状：

典型的故障是A429 ACARS输出（输出#4）性能下降。然而，随着故障模式的发展，这可能成为该输出端口的持续故障。在极端情况下，其他A429和程序引脚可能受到影响。

• 无当前腿部故障（PLF）和实时事件（RTE）报告通过ARINC通信寻址和报告系统（ACARS）数据链下行。
• 无CFM LEAP EEC报告通过ACARS数据链下行至地面。
• 过去10个飞行腿中超过10次的维护消息23-23010（CMU未从NFS-L接收到机舱终端#1的输入）。
• 不受影响：PLF和故障历史（FH）报告通过无线网络或Gatelink下行至可加载软件飞机部件库（LSAPL）
不受影响：能够从多功能显示系统（MDS）或维护笔记本电脑访问PLF、FH和进站飞行甲板效果

## 连接器焊接接头故障背景：

• 开启服务相关问题737MAX-SRP-46-0006以调查NSP连接器问题
• 初步调查表明，内部电路卡组件（CCA）连接器承受的力超出设计。
• 已确定焊接接头故障的根本原因。

# 状态

## SSD状态：

• Teledyne Controls选择了固态硬盘（SSD）的另一供应商：ATP Electronics。
• ATP Electronics SSD采用更新的技术、改进的固件和架构。
• ATP Electronics SSD提供电源保护功能，确保优雅关机。
• ATP Electronics SSD内置的电源保护功能需要在手动重置期间完全断电。如果使用断路器，确保断开至少三秒钟后再重新通电。
• Teledyne Controls用ATP Electronics SSD替换返回单元中失败的Delkin SSD。
• 生产单元（从S/N 47B01090开始）正在交付ATP Electronics SSD。请参阅服务公告（SB）以获取适用的序列号
• 通过Mod Dot和序列号跟踪更换SSD的现场返回。Teledyne Controls服务公告（SB）SB2247200-46-7已发布，适用于NFS P/N 2247200-01，并列出了NFS序列号的有效性。
Teledyne将在2021年第一季度末发布以下服务公告。Teledyne Controls服务公告（SB）SB2247200-46-12已发布，适用于NFS P/N 2247200-01 Teledyne Controls服务公告（SB）SB2247200-46-15已发布，适用于NFS P/N 2247200-03

## 连接器焊接接头状态：

维护消息23-23010（CMU未从NFS-L接收到机舱终端#1的输入）对于预测连接器问题是有效的。
Teledyne进行了故障分析并修改了设计，以机械方式断开网络扩展设备（NED）子系统处理器（NSP）与服务器子系统处理器（SSP）模块组件的连接。
• 已确定根本原因。NSP连接器：NFS中的机械公差叠加和连接器上使用的环氧树脂的不同热膨胀性质导致机械应力，从而在连接器与印刷线路板之间的焊接接头产生裂纹。
• Teledyne将在2021年第一季度末发布以下服务公告。

Teledyne SB SB2247200-46-13取代SB2247200-46-9，已发布，适用于NFS PN 2247200-01。
Teledyne SB SB2247200-46-14已发布，适用于NFS PN 2247200-03。

# 临时行动

如果NFS出现讨论部分描述的症状，请按照AMM任务46-13-01-000-801（网络文件服务器系统拆除）拆除NFS，并按照AMM任务46-13-01-400-801（网络文件服务器系统安装）更换NFS。

# 最终行动

Boeing建议航空公司运营商将故障的NFS单元送回Teledyne Controls进行维修。

已确定NSP连接器的根本原因：NFS中的机械公差叠加和连接器上使用的环氧树脂的不同热膨胀性质导致机械应力，从而在连接器与印刷线路板之间的焊接接头产生裂纹。

实施Teledyne SB SB2247200-46-13，适用于NFS PN 2247200-01，以及Teledyne SB SB2247200-46-14，适用于NFS PN 2247200-03。

结束此技术文档
