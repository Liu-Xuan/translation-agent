# FLEET TEAM DIGEST（FTD）  

# 737MAX-FTD-31-23004  

**问题标题**：起飞警报抑制选项  

![](images/8485828948872f601eab09dbe10a50dd469392a2cea91ec8cf88049546d78d1c.jpg)  

# 改版说明  

更新了可选服务公告的预计完成日期（ECD）。  

# 适用范围  

所有737MAX飞机。  

# 问题描述  

波音公司已确定选项选择软件（OSS）参数OSS_TO_ALERT_INH_800FT存在问题。  

# 背景  

起飞警报抑制功能旨在抑制发动机警报信息的闪烁，如《飞行机组操作手册》（FCOM）第7章（发动机、APU）第10节（控制和指示器：机组警报）中所述。该抑制功能的设计目的是通过禁用OSS参数并在400英尺（ft）无线电高度（RA）以下抑制闪烁，从而在80节（kts）至400英尺RA之间减少飞行员的分心。然而，现已确定该参数被反转，导致抑制功能在800英尺RA以下均处于启用状态。  

# 注意：  

- 发动机警报信息仍会显示，且母机要求仍得到满足；要求并未指定机组警报的闪烁或抑制行为。  
- 此问题被判定为非安全问题。  

# 状态  

波音公司将发布《飞行机组操作手册公告》（OMB），以反映设计与实际行为之间的当前差异。  

适用的FCOM第2卷（V2）系统描述也将进行修订，以反映这些变更，目标发布日期为11月23日。  

最终修复将作为下一代MAX显示系统（MDS）BlockPoint（BP）版本MDS BP 2的一部分发布。  

有关MDS BP2的当前状态和发布时间表，以及MDS BP 2版本中解决的FLEET TEAM DIGEST（FTD）文章列表，请参阅737MAX-FTD-31-23002。  

# 临时措施  

波音公司已确定两种临时行动方案：  

（1）运营商可以继续在800英尺RA的OSS参数反转状态下飞行。  

如果选择此行动方案，运营商应考虑主动与飞行机组沟通，告知发动机警报的闪烁将在与FCOM第7.10章所述不同的范围内（最高800英尺RA，而非最高400英尺RA）被抑制。  

请注意，OSS参数OSS_TO_ALERT_INH_800FT的设计目的是在受影响的飞机起飞期间，从80节指示空速（KIAS）至400英尺RA（如FCOM所述）或达到80节后30秒（以先到者为准）抑制警报；然而，目前抑制功能在800英尺RA或达到80节后30秒内均处于启用状态。  

（2）波音公司将发布一份可选服务公告（SB 737-31-2108），适用于运行MDS OPS（操作程序软件）SW BP 1.5.1的在役飞机，以恢复到预期的400英尺RA抑制配置，直至MDS BP 2发布。  

当服务公告可用时，请通过My Boeing Fleet提交服务请求，或联系您的现场服务代表，并参考PRR 3M9900-100R和/或SB 737-31-2108。  

# 最终措施  

当可用时，请纳入MAX显示系统（MDS）BlockPoint（BP）2版本MDS BP 2。这将使行为恢复到预期的400英尺RA抑制状态。  

有关MDS BP2的当前状态和发布时间表，请参阅737MAX-FTD-31-23002。
