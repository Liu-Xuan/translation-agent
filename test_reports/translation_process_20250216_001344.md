# 机队团队摘要  

737MAX-FTD-46-19002  

问题标题：网络文件服务器2（NFS-2）硬件相关问题  

![](images/6a5f0a361f745e3854a0f08ea7716af61d5e9f0bada7338e144811c38c102576.jpg)  

# 修订说明  

修订了状态部分、最终行动和里程碑部分，增加了连接器焊点故障的日期。  

# 适用性  

适用于以下状态部分中提到的NFS序列号（S/Ns）的737 MAX飞机。  

# 描述  

737MAX运营商遇到了网络文件服务器（NFS）问题。目前，已知的NFS硬件相关问题有两个：固态硬盘（SSD）和网络扩展设备（NED）子系统处理器（NSP）连接器故障。  

## SSD故障症状：  

• NFS前面的故障灯在启动后持续亮起超过10分钟。  

## SSD故障背景：  

• Delkin（SSD供应商）的故障分析未能确定根本原因。  
• Delkin尝试通过固件更新解决问题，但未产生积极效果。  
• 主要假设是SSD在写入时容易受到电源中断的影响。  

## 连接器焊点故障症状：  

典型的故障是A429 ACARS输出（输出#4）的性能下降。然而，随着故障模式的发展，这可能会成为该输出端口的持续故障。在极端情况下，其他A429和程序引脚可能会受到影响。  

• 没有通过ARINC通信寻址和报告系统（ACARS）数据链下传的当前航段故障（PLF）和实时事件（RTE）报告。  
• 没有通过ACARS数据链下传到地面的CFM LEAP EEC报告。  
• 在过去10个航段中，维护信息23-23010（CMU在机舱终端#1上没有来自NFS-L的输入）的实例过多（10次或更多）。  
• 不受影响：PLF和故障历史（FH）报告通过无线网络或Gatelink下传到可加载软件飞机部件库（LSAPL）。  
• 不受影响：能够通过多功能显示系统（MDS）或维护笔记本电脑访问PLF、FH和进港驾驶舱影响。  

## 连接器焊点故障背景：  

• 服务相关问题737MAX-SRP-46-0006已开启，以调查NSP连接器问题。  
• 初步调查表明，内部电路卡组件（CCA）连接器承受的力超过了设计范围。  
• 焊点故障的根本原因已确定。  

# 状态  

## SSD状态：  

• Teledyne Controls选择了ATP Electronics作为固态硬盘（SSD）的替代供应商。  
• ATP Electronics SSD采用了更新的技术，具有改进的固件和架构。  
• ATP Electronics SSD提供了电源保护功能，以确保优雅的关机。  
• ATP Electronics SSD内置的电源保护功能确实要求在手动重置期间完全循环NFS的电源。如果使用断路器，请确保在重新供电前至少拔出三秒钟。  
• Teledyne Controls正在用ATP Electronics SSD替换返回的故障Delkin SSD单元。  
• 生产单元（从S/N 47B01090开始）正在交付带有ATP Electronics SSD的NFS。请参阅服务公告以了解适用的序列号。  
• 带有替换SSD的现场返回单元正在通过Mod Dot和序列号进行跟踪。Teledyne Controls服务公告（SB）SB2247200-46-7已发布，适用于NFS P/N 2247200-01，并列出了NFS序列号的适用性。  
Teledyne将在2021年第一季度末发布以下服务公告。Teledyne Controls服务公告（SB）SB2247200-46-12已发布，适用于NFS P/N 2247200-01。Teledyne Controls服务公告（SB）SB2247200-46-15已发布，适用于NFS P/N 2247200-03。  

## 连接器焊点状态：  

维护信息23-23010（CMU在机舱终端#1上没有来自NFS-L的输入）有效用于预测连接器问题的警报。  
Teledyne进行了故障分析，并修改了设计，以机械方式将网络扩展设备（NED）子系统处理器（NSP）与服务器子系统处理器（SSP）模块组件断开连接。  
• 根本原因已确定。NSP连接器：NFS中的机械公差叠加以及连接器上使用的环氧树脂的不同热膨胀特性导致了机械应力，从而在连接器和印刷线路板之间的焊点处产生了断裂。  
• Teledyne将在2021年第一季度末发布以下服务公告。  

Teledyne SB SB2247200-46-13取代了SB2247200-46-9，并已发布，适用于NFS PN 2247200-01。  
Teledyne SB SB2247200-46-14已发布，适用于NFS PN 2247200-03。  

# 临时行动  

如果NFS表现出讨论部分中描述的症状，请按照AMM任务46-13-01-000-801（网络文件服务器移除）移除NFS，并按照AMM任务46-13-01-400-801（网络文件服务器安装）更换NFS。  

# 最终行动  

波音建议航空公司运营商将故障的NFS单元送回Teledyne Controls进行维修。  

根本原因已确定。NSP连接器上的机械公差叠加以及连接器上使用的环氧树脂的不同热膨胀特性导致了机械应力，从而在连接器和印刷线路板之间的焊点处产生了断裂。  

实施Teledyne SB SB2247200-46-13，适用于NFS PN 2247200-01，以及Teledyne SB SB2247200-46-14，适用于NFS PN 2247200-03。
